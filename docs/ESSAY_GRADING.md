# 申论批改验收与评分口径

## 评分与证据

- 原题满分来自题库 `paper_questions.score`，报告显示 `score / maxScore`；各维度上限和得分分别与本题满分、总分相加一致。跨题统计使用得分率，不直接平均20分题和40分题的原始分。
- 小题六维：要点踩中50%、概括准确15%、内容全面10%、分类逻辑10%、规范简洁10%、格式字数身份5%。大作文七维：立意25%、扣题15%、内容10%、论证20%、结构15%、语言10%、标题与形式5%。这是教学量表，不是官方赋分细则。
- 小题先仅依据题干和材料建立参考要点，再评阅考生答案；参考点按题目内容与模型版本缓存，避免根据考生答案反推标准。采点部分完整覆盖得全点分、部分覆盖得一半、遗漏或错误得0分。其他维度要求避免重复扣同一项遗漏。
- 材料使用段落编号绑定，程序从指定段落还原原文；可核验的连续短引文优先展示。采点分析、失分诊断均支持考生原句编号，由程序还原真实引文，虚构编号或原文仍会被拒绝。缺失逐句批注、超满分、缺少参考答案、参考答案超字数等情况均触发校验失败并按阶段重新生成；诊断最多两次。范文首次生成后按版本独立校验，每个不合格版本最多修订三次，保留已合格版本；修订使用实际字数和目标字数做专门压缩或补足，不截断正文。
- 参考估分范围是围绕中心分按满分约8%（至少1分）给出的教学波动提示，未经真人阅卷校准，不称为统计置信区间。没有真实同题样本排名时只给水平判断。

## 报告页面

1. 总分、原题满分、水平、参考估分范围、六维/七维分项。
2. 标准参考点、已踩中/部分/遗漏/错误筛选、材料原句、提炼解释、考生原句、对应改写。
3. 每句原答案的有效信息/重复/背景/无效/错误判定，具体改写及原因。
4. 失分原文、问题位置、失分原因、完整替换文字和修改依据；字数、超限、信息比例和每100字要点数量。
5. 结构节点与层级关系检查。对策题单列问题—原因—对策表；公文题检查身份、对象、目的、文种、格式、语气。
6. 大作文单列立意、题眼关系、标题、扣题、分论点、材料使用、论证、开头结尾等检查，以及逐段论证链和示范改写。
7. 考场稳妥版、高分优化版、压缩练习版，每版包含完整文本、组织思路、取舍原因和句段拆解。大作文压缩版明确是提纲，不冒充完整考场作文。
8. 针对薄弱能力的练习数量、方法、验收标准和题型入口；有相同参考标准下的历史同题记录时展示得分率变化。

字数按非空白字符（含标点）计数。信息分类由AI判断，再由服务端按句汇总，部分有效句暂按一半字数估计；信息密度指标属于估算。文本提交无法判断真实手写字迹或卷面。

## 持续记录

`/api/real-papers/essay-profile` 根据当前用户最近500条已完成批改中的新版申论报告统计采点率、遗漏率、有效覆盖率、平均字数、超限比例、各题型得分率、各维度表现、常见错误和趋势。作文材料覆盖仅作诊断，不按小题要点赋分。旧版报告不混入新版错误画像。

题库覆盖页区分未收录与没有考试；年份/地区/实际卷别/题型可筛选，列表自动读取所有分页。来源完整性仍以 [题库覆盖清单](ESSAY_BANK_COVERAGE.md) 为准。

## 兼容与恢复

- 历史百分制报告保留原样，申论旧报告详情提供重新批改入口。
- 新提交保存题目快照和本题满分，避免之后改题导致历史分值变动。
- 每批两题并发，批量保存结果并刷新进度；前端自动轮询。失败保留具体原因，重试只处理未完成题目。
- 当前为单实例PM2服务。启动时把上次进程中断的任务标为失败，使用户可以重试，不永久停留在“批改中”。多实例部署需先改为共享队列和租约，不能直接扩容实例数。
- 本地测试目录已忽略，不加入Git或发布包。
